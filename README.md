# 📚 RAG知识库系统

一个用 Python 做的小型 AI 知识库项目。

用户可以上传 PDF，系统会自动读取文档内容，并根据提问返回相关信息。项目使用 Streamlit 搭建网页界面，适合作为 AI 应用 / Python Web / RAG 入门项目。

---

## ✨ 项目功能

- 支持 PDF 文件上传
- 自动解析 PDF 文本
- 根据关键词检索相关内容
- 生成简单 AI 风格回答
- Web 可视化交互界面

---

## 🛠 技术栈

- Python
- Streamlit
- PyPDF
- RAG（检索增强生成）
- 文本检索
